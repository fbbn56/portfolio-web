# Bharat — Personal Portfolio Website

A clean, modern, minimalist developer portfolio crafted with **React.js**, **Tailwind CSS**, and inspired by the aesthetic monochrome manga/sketch developer theme.

---

## 👨‍💻 About Bharat
- **Role:** Web Developer
- **Education:** First Year, Computer Science & Engineering (B.Tech) at **JECRC University**, Jaipur
- **Primary Technical Skills:** Python and C Language
- **Hackathon Participation:** **Smart India Hackathon (SIH) 2026**

---

## 🎨 Design Features (Inspired by Reference Theme)
1. **Floating Capsule / Pill Navbar**:
   - Modern glassmorphic floating pill with Home, About, Projects, Services, Contact.
   - Smooth active state tracking and dark/light mode toggle.
2. **Hero Section**:
   - Status badge: `. Available for freelance work & hackathons`
   - Large bold typography: `Hi, I'm Bharat`
   - Animated typewriter role: `Web Developer |` alternating between Python, C, and SIH 2026.
   - Meta tags: JECRC University, Jaipur, and SIH 2026.
   - `→ Hire Me` & `📥 Download CV` buttons with horizontal divider line.
   - Social icon links (`GitHub`, `Discord`, `LinkedIn`, `Instagram`, `Email`).
   - Iconic programmer desk illustration matching the reference screenshot.
3. **Dedicated Sections**:
   - **About**: Journey from C memory mechanics to Python automation and React UI at JECRC University.
   - **Skills & Services**: In-depth breakdown of Python, C, React.js, and Hackathon prototyping.
   - **Hackathons Showcase**: Dedicated spotlight on **Smart India Hackathon 2026**.
   - **Featured Projects**: Filterable project catalog (SIH 2026 Prototype, C In-Memory Cache, Python Automations, Web apps).
   - **Interactive Contact Form**: With live validation and 1-click email copy.
   - **Interactive CV Modal**: Preview and download resume document.

## 🚀 How to Run

### Method 1: One-Click Run (Double-Click)
- Double-click `start.bat` in the `bharat-portfolio` folder. It will start the server and automatically launch your default browser at `http://localhost:5000`.

### Method 2: Python Command Line
```powershell
cd c:\Users\God\Desktop\bharat-portfolio
python run_server.py
```

### Method 3: Direct Browser Open
You can also directly double-click `index.html` to open it in Chrome, Edge, Brave, or Firefox.
